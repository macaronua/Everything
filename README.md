# Everything

Особистий репозиторій нотаток і систем.

## Зміст

- [`docs/book-notes-workflow.md`](docs/book-notes-workflow.md) — воркфлоу
  опрацювання книжок через NotebookLM (карта структури → ядро книжки →
  конспект → фінальна версія → синтез знань через кожні 5–10 книжок).
- [`books/`](books/) — конспект кожної книжки в окремому файлі
  (`_template.md` — шаблон, `INDEX.md` — таблиця всіх книжок).
- [`knowledge-base/`](knowledge-base/) — тематичні синтези кількох книжок
  (Крок 6 воркфлоу).
