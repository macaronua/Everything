# База знань (синтез)

Тематичні синтези за Кроком 6 воркфлоу — після кожних 5–10 опрацьованих
книжок.

Кожен файл тут — одна тема (наприклад `myslennia.md`, `hroshi.md`,
`pryinyattia-rishen.md`), де зводяться ідеї з кількох книжок: що
підтверджується різними авторами, що доповнює одне одного, а де є
суперечності.

Джерело для кожного синтезу — теги (`tags`) у файлах `books/*.md`.

Файли з'являться тут після першого циклу синтезу.
