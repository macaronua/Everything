# Воркфлоу опрацювання книжок (NotebookLM → конспект 15–20%)

Система для перетворення прочитаної книжки на компактний, але змістовно повний конспект. Використовується щоразу в однаковій послідовності — окремий Notebook у NotebookLM на кожну книжку.

## Крок 1. Завантаж книжку в NotebookLM

Створи окремий Notebook, додай повний файл книги, встав перший запит:

```
Проаналізуй всю книжку та створи детальну карту її структури.
Для кожного розділу визнач:
- головне питання або проблему;
- центральну тезу;
- найважливіші поняття;
- важливі докази, дослідження, експерименти та приклади;
- практичні висновки.

Поки що не скорочуй матеріал надто сильно. Моє завдання на цьому етапі —
зрозуміти структуру та логіку всієї книжки.
```

## Крок 2. Визнач ядро книжки

Після першої відповіді:

```
Визнач ідеї, без яких неможливо повноцінно зрозуміти головну думку автора.
Розділи матеріал на чотири категорії:
1. Ключові ідеї — обов'язково зберегти.
2. Важливі допоміжні ідеї.
3. Докази, дослідження та приклади.
4. Повтори, довгі історії та другорядні приклади, які можна прибрати без
   втрати розуміння.

Кінцева мета — залишити приблизно 15–20% найціннішого змісту книжки, але
максимально зберегти її інтелектуальну цінність та логіку аргументації.
```

## Крок 3. Створи великий структурований конспект

```
На основі всієї книжки створи детальний структурований конспект.
Обов'язково збережи:
- головну тезу автора;
- ключові концепції та їх визначення;
- важливі аргументи та логіку автора;
- найважливіші дослідження й експерименти;
- приклади, без яких складно зрозуміти певну ідею;
- практичні висновки;
- важливі застереження, винятки та обмеження.

Прибери повтори, довгі історії та приклади, які лише повторюють уже
пояснену думку. Не спрощуй складні концепції настільки, щоб втрачався
їхній зміст. Пиши українською мовою.
```

## Крок 3.5. Перевір ключові факти

NotebookLM додає до відповідей клікабельні цитати з посиланням на конкретне
місце в книзі — це швидко, тому варто цим користуватися. Перед тим як
передавати конспект далі, попроси перевірку найважливіших тверджень:

```
Виведи список усіх цифр, статистики, результатів досліджень та імен
дослідників/експериментів, згаданих у конспекті, разом із точним
цитуванням джерела (сторінка/розділ) для кожного.
```

Пробіжись клікабельними цитатами по 3–5 найважливіших цифрах чи
дослідженнях (ті, на яких тримається головний аргумент автора) — це займає
секунди, але захищає від типової проблеми LLM: спотворення чи вигадування
конкретних даних під час стиснення тексту.

## Крок 4. Передай результат Claude

Завантаж отриманий матеріал (файл або текст) і напиши:

```
Це матеріал NotebookLM по книзі [назва]. Зроби фінальний конспект за
нашою системою 15–20%.
```

Claude перевіряє структуру, прибирає залишкові повтори, пояснює складні
місця простіше й визначає, що справді варто залишити.

## Крок 5. Фінальна версія

Однакова структура для кожної книжки:

1. **Книга за 2 хвилини** — про що вона і яка головна теза.
2. **Основний конспект 15–20%** — повноцінний матеріал для читання замість
   усієї книги.
3. **Ключові концепції** — термін → пояснення → приклад.
4. **Головні дослідження та докази** — що саме підтверджує аргументи автора.
5. **Практичне застосування** — як використати знання в реальному житті.
6. **Що запам'ятати** — приблизно 10–20 найважливіших думок.
7. **Критичний аналіз** — слабкі місця книги, спірні твердження, застарілі
   дослідження та те, що сучасна наука могла уточнити після виходу книги.
8. **Зв'язки з іншими книжками** — які вже прочитані ідеї підтверджують,
   доповнюють або суперечать цій книжці.

## Крок 6. Через кожні 5–10 книжок — синтез знань

Перестаємо дивитися на книги окремо й об'єднуємо їх за темами: мислення,
психологія, гроші, бізнес, прийняття рішень, історія, наука тощо.

Через умовні 30 книжок це дає не просто 30 скорочених книжок, а власну
структуровану базу знань, де видно зв'язки між авторами та ідеями.
